# 網頁精選照片資料夾 (Curated Web Images)

本資料夾 `web_assets/images/` 專門存放成果展網站（`index.html`）所精選展示的照片與圖形素材。

## 協作指引

1. **原圖來源**：可由專案內的 `04 活動照片` 中挑選優質、具代表性的照片。
2. **建議格式與大小**：
   - 格式：`.jpg`、`.webp` 或 `.png`。
   - 尺寸：長邊建議在 `1200px ~ 1920px` 之間（Retina 螢幕清晰，載入飛快）。
   - 容量：單張檔案建議壓在 `200KB ~ 500KB`，避免成果展現場手機 4G 網路延遲。
   - 避免直接放入未轉檔的 `.HEIC` 原檔（部分瀏覽器無法直接渲染）。
3. **在網頁中擴充照片**：
   - 將新照片放置於此資料夾（例如 `new_photo.jpg`）。
   - 在 `index.html` 的「精選現場照片牆（`#gallery`）」區塊複製貼上一組 `<a>` 標籤並更新檔名與圖說。
   - 執行 `git commit` 與 `git push`，GitHub Pages 便會自動更新！
